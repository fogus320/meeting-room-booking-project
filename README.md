# ระบบจองห้องประชุมออนไลน์ (Meeting Room Booking System)

## Project Description
ระบบเว็บแอปพลิเคชันสำหรับค้นหาและจองห้องประชุมออนไลน์ พร้อมระบบตรวจสอบและป้องกันการจองช่วงเวลาซ้อนทับ (Real-time Overlap Protection)

## Objectives
- เพื่อให้ผู้ใช้งานค้นหาและตรวจสอบสถานะห้องประชุมว่างได้แบบ Real-time
- เพื่อป้องกันปัญหาการจองห้องประชุมซ้ำซ้อนกันในช่วงเวลาเดียวกัน
- เพื่อจัดเก็บข้อมูลการจองลงในฐานข้อมูลอย่างเป็นระบบ

## Target Users
- พนักงานและบุคลากรภายในองค์กรที่ต้องการจองห้องประชุม
- ผู้ดูแลระบบ (Admin) ที่จัดการข้อมูลห้องประชุมและอุปกรณ์

## Main Features
- ค้นหาห้องประชุมตามวัน เวลา และความจุ
- จองห้องประชุมล่วงหน้า
- ระบบตรวจสอบช่วงเวลาซ้อนทับ (Overlap Checking Algorithm)
- แสดงรายการห้องประชุมบนหน้าแรก
## Technology
- Frontend: React.js (Vite)
- Backend: Node.js, Express.js
- Database: MySQL
